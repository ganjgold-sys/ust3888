# Сайт ООО «Юстиция» — банкротство и юридическая помощь в Иркутске

Одностраничный сайт на React 19 + Vite + Tailwind CSS 4 с сервером Express.

## Быстрый старт

**Требуется:** Node.js 18 или новее.

```bash
npm install      # установка зависимостей
npm run dev      # запуск на http://localhost:3000
npm run build    # production-сборка в папку dist
npm start        # запуск собранной версии
```

Для работы AI-консультанта создайте файл `.env.local` и укажите ключ:

```
GEMINI_API_KEY="ваш_ключ"
```

Без ключа AI-консультант отвечает заранее заданным текстом (заглушкой) — сайт при этом работает.

## Оптимизация скорости загрузки

Замеры сборки (gzip):

| Что | Было | Стало |
|---|---|---|
| Первый экран (JS + CSS + HTML) | ~165 КБ одним файлом | ~97 КБ, из них 69 КБ — React (кешируется) |
| Картинка первого экрана | 99 КБ | 36 КБ на телефоне / 66 КБ на десктопе |
| Библиотека анимаций на первом экране | 42 КБ | не загружается |
| Остальные секции | в общем бандле | отдельные чанки, по мере прокрутки |

Что сделано:

1. **Разделение бандла на чанки** (`manualChunks`): react, motion, icons, приложение.
   Хешированные файлы кешируются на год, поэтому при обновлении сайта
   пользователь скачивает только изменившееся.
2. **Ленивая загрузка секций** (`src/components/LazyOnVisible.tsx`): всё ниже первого
   экрана подгружается при прокрутке (за 600 px до появления). Модальные окна
   вынесены в отдельные чанки и грузятся при первом открытии.
3. **Библиотека анимаций убрана с первого экрана.** Анимации шапки, первого экрана
   и мобильного меню переписаны на CSS-кейфреймы. `motion` остаётся только в
   секциях ниже и грузится вместе с ними. Учтён `prefers-reduced-motion`.
4. **Изображение первого экрана** отдаётся в двух размерах через `srcSet`
   (640w / 1000w), с явными `width`/`height` — без сдвига вёрстки.
5. **Сжатие gzip** на сервере (`compression`) и заголовки кеширования:
   `assets/*` — год с `immutable`, `index.html` — `no-cache`.
6. **Ссылки-якоря работают** даже при ленивой загрузке: `LazyOnVisible` принимает
   `anchorId` и рендерит секцию сразу, если перешли по `#services`, `#faq` и т.п.

Проверка: `NODE_ENV=production npm run dev` → отдаёт `Content-Encoding: gzip`
и `Cache-Control: public, max-age=31536000, immutable` для файлов сборки.


## Адаптивность и исправление прокрутки

**Сброс прокрутки наверх при подгрузке блоков — исправлено.**

Причина: граница `<Suspense>` была одна на всю страницу (`<main>`). Когда
подгружался очередной ленивый блок, React заменял заглушкой весь контент,
высота документа падала почти до нуля, и браузер принудительно прокручивал
страницу в начало. Выглядело как «выкинуло на первый экран».

Что сделано:
- Внешний `Suspense` из `App.tsx` убран полностью.
- `LazyOnVisible` теперь держит **свой** `Suspense` с заглушкой той же высоты,
  что и сам блок (`contain: layout style`). Секция подгружается на месте,
  остальная страница не перерисовывается.
- Заглушка занимает место блока, поэтому высота страницы не скачет
  и прокрутка сохраняется.

**Ширина под разные экраны.**

- Введён класс `.site-container` (в `src/index.css`) вместо жёсткого
  `max-w-7xl` (1280px): ширина до **1680px**, на экранах 1920px+ — до 1800px,
  боковые отступы растут плавно: `padding-inline: clamp(1rem, 3vw, 4rem)`.
- Заменён во всех секциях: шапка, первый экран, услуги, калькулятор, кейсы,
  отзывы, команда, сравнение, FAQ, контакты, подвал.
- Текстовые блоки ограничены `.site-container-narrow` (1400px), чтобы строки
  не растягивались на всю ширину монитора и оставались читаемыми.
- `8xl`/`2xl` варианты сеток добавлены для карточек на очень широких экранах.

## Чередование фонов секций и блок видео

**Фоны.** Секции идут по очереди: тёмная → светлая → тёмная.

Светлая тема задаётся классом `.theme-light` в `src/index.css`. Внутри секции

текст меняются вместе с фоном без правки компонентов. Чтобы поменять порядок,
достаточно переставить класс `theme-light` в нужной секции.

(`preload="none"`).
